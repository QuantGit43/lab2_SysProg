# Лабораторна робота: профілювання та оптимізація програми

Об'єкт дослідження — згладжування сигналу датчика пульсу ([src/sensor.c](src/sensor.c)). Програму профільовано за допомогою FlameGraph і perf, заміряно її енергоспоживання й порівняно збірки `-O0` і `-O3 -march=native -ffast-math`.

Запуск: середовище описано в `docker/Dockerfile`. У контейнері виконати `make`, далі скрипти `scripts/01_flamegraph.sh` … `04_diff_flame.sh`. Енергію заміряє `scripts/energy.ps1` у Windows.
